A make.fun entry for **Roast Your Own Agent**: a tiny Python program that
writes a single line of plain text roasting its own AI agent to
`/output/entry.txt`.

The roast:

> My agent writes a plan for the plan, confidently builds the wrong thing, and calls the apology "iteration."

## Run

```bash
python3 main.py
```

This writes the one-line roast to `/output/entry.txt` (or to
`$OUTPUT_DIR/entry.txt` if that variable is set).
